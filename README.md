### 👨‍💻 About Me

I am an **AI Engineer & Systems Developer** dedicated to building resilient, production-grade retrieval engines, multi-agent frameworks, and enterprise software:

- 🚀 **Creator of [`graphrag-atlas`](https://github.com/R-Mabasha/graphrag-atlas)**: An open-source framework providing Single-Store Hybrid GraphRAG on MongoDB Atlas (BM25, Dense Vectors, Bounded 2-hop `$graphLookup`, Hub Guard circuit breaker, and two-tier tenancy). Live on [PyPI](https://pypi.org/project/graphrag-atlas/) via `pip install graphrag-atlas`.
- 🤖 **MCP (Model Context Protocol) Architect**: Designing local-first, zero-dependency MCP servers and agent memory architectures ([`antigravity-project-memory`](https://github.com/R-Mabasha/antigravity-project-memory), [`Multi-Agent-Mcp`](https://github.com/R-Mabasha/Multi-Agent-Mcp)).
- ⚡ **Specialized in RAG Lifecycles**: Multi-modal fusion (RRF $k=60$), cross-encoder reranking, graph super-node pruning, and incremental SHA-256 diff caching.
- 🏢 **Enterprise Integration**: Proven track record in TypeScript/Python microservices, Node-RFC SAP integration, and high-concurrency databases.
- 🌐 **Interactive Portfolio**: Explore my interactive web apps and projects at **[coders2345.github.io/Mabasha-Portfolio](https://coders2345.github.io/Mabasha-Portfolio)**.
